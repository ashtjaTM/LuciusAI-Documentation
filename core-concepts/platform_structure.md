# Platform Structure

## Introduction

Lucius AI uses a hierarchical structure to organize testing assets. The platform is organized into Organizations and Projects, allowing teams to separate workspaces while managing test assets efficiently.

The top navigation bar contains Organization and Project selectors, making it easy to switch between the workspaces you have access to.

# Organization

## What is an Organization?

An Organization represents your company, team, or business unit and serves as the top-level container within Lucius AI. Organizations help you group and manage related projects, users, and testing assets under a single workspace.

Depending on your subscription plan, your account may support either a single organization or multiple organizations. The ability to create, edit, delete, or manage organizations is determined by your assigned role and permissions.

## Creating an Organization

If your subscription plan and assigned role allow organization creation, you can create a new organization in either of the following ways:

### Method 1

- Open the Organization selector in the application header.
- Select **Create New Organization**.

### Method 2

- Click the **+** button in the application header.
- Select **Add Organization**.

### Provide:

- Organization Name
- Short Description (optional)
- Then click **Create**.

## Managing Organizations

Depending on your assigned role, you can:

- Edit organization details.
- Access Organization Settings.
- Delete an organization.
- Switch between available organizations using the organization selector.

# Project

## What is a Project?

A Project is a dedicated workspace within an organization where you manage your testing activities for a specific application, product, feature, or release.

Each project maintains its own test cases, test suites, modules, parameters, browser profiles, tunnel providers, execution history, and project settings, allowing teams to organize testing assets independently.

Project creation and management are subjected by your assigned role and permissions.

## Creating a Project

If your assigned role allows project creation, you can create a project in either of the following ways.

### Method 1

- Open the Project selector in the application header.
- Select **Create New Project**.

### Method 2

- Click the **+** button in the application header.
- Select **Add Project**.

### Provide:

- Select Organization
- Project Name
- Short Description (optional)
- Then click **Create**.

## Managing Projects

Depending on your assigned role, you can:

- Edit project details.
- Access Project Settings.
- Delete projects.
- Switch between projects using the project selector.

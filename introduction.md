# Introduction

Welcome to the **Lucius AI** documentation.

Lucius AI is an AI-powered UI test automation platform that simplifies the way teams create, execute, and maintain automated tests. Instead of manually building automation scripts, you can describe a test case in natural language or interact with your application using AI, and Lucius AI generates robust Playwright-based test automation for you.

Designed for modern quality engineering teams, Lucius AI combines AI-assisted test generation, reusable automation assets, cloud-based execution, and detailed execution insights into a single platform. Whether you're validating a new feature, performing regression testing, or maintaining an existing automation suite, Lucius AI helps accelerate testing while reducing manual effort and long-term maintenance.

This documentation walks you through every stage of the platform—from generating your first AI-powered test case to executing tests, analyzing results, and managing reusable automation components.

# What You Can Do with Lucius AI

Lucius AI supports the complete UI test automation workflow.

Using the platform, you can:

- Generate Playwright-based test cases using natural language.
- Create tests through **Scenario Mode** or interactive **Agent Mode**.
- Import and manage existing test cases.
- Build reusable automation using **Modules** and **Parameters**.
- Execute tests in cloud browser environments.
- Access applications running on private networks using **Tunnel Providers**.
- Reuse authenticated sessions through **Browser Profiles**.
- Organize regression testing with **Test Suites**.
- Review execution history, Playwright traces, execution videos, screenshots, and HTML reports.

# Organize and Search Test Cases

The **Test Cases** workspace provides options to organize test cases into folders and quickly locate them using search and filters. Test cases and folders can be managed directly from the workspace without navigating away from the test case list.

## Organize Test Cases

Test cases can be organized into folders to maintain a structured test case hierarchy within the project.

The workspace provides the following options:

- **Folders:** Create folders to group related test cases and maintain an organized test case structure. Folders can contain test cases and additional folders, allowing test cases to be organized across multiple levels.
- **Expand/Collapse:** Expand or collapse a folder to view or hide the test cases and folders within it.
- **Move and Arrange:** Use the drag handle available beside folders and test cases to arrange them within the workspace.
- **Select:** Select test cases or folders using the selection control. Multiple test cases and folders can be selected at the same time.
- **Export:** Export selected test cases to **GitHub** from the **Test Cases** workspace.

The workspace also provides separate tabs for **Test Cases** and **Imported Test Cases**, allowing users to switch between generated test cases and imported test case records.

## Search & Filter

The **Test Cases** workspace provides search and filter options to help users locate test cases based on their name, status, and test status.

- **Search:** Use the **Search** bar to search for test cases.
- **Filters:** Select the **Filter** icon to open the Filters panel.

The Filters panel provides the following options:

### Status

- **Draft**
- **Active**
- **Archived**
- **Deprecated**

### Test Status

- **Passed**
- **Partially Passed**
- **Failed**
- **Pending**

Users can select the relevant options from the Filters panel to narrow down the test cases displayed in the workspace.

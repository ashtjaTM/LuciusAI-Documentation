# Test Cases Workspace

The **Test Cases Workspace** is the central area for creating, organizing, managing, and working with test cases within a project. It brings together the test cases available in the project and provides access to the actions required throughout the test automation workflow.

LuciusAI supports two approaches for generating test cases:

* **Scenario Mode** – Allows you to define a test scenario using structured, step-by-step instructions in natural language describing the intended workflow.
* **Agent Mode** – Allows you to provide an objective in natural language, after which the agent explores the application and generates relevant test scenarios based on the provided objective.

LuciusAI is designed around describing test cases in **plain English** and generating **Playwright scripts** for automated UI testing.

## Workspace Layout

The Test Cases Workspace provides the following areas and actions:

**Test Case List**: Displays the test cases available within the selected project. Test cases can be organized into folders to maintain a structured testing workspace.

**Folders**: Folders allow you to organize related test cases together. You can create folders and use them to maintain a logical structure for your test cases.

**Search**: Allows you to quickly locate a test case within the workspace.

**Filter**: Allows you to narrow down the displayed test cases based on the available filtering options.

**Import**: Allows you to import existing test cases into LuciusAI. LuciusAI supports importing existing test cases as part of its test automation workflow.

**Export**: Allows you to export test cases to the supported destination available in LuciusAI
